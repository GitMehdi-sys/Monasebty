# Security Policy

## Supported Versions

Only the latest version on the `main` branch receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: go to the **Security** tab of this repository and click **Report a vulnerability**.

Include:
- A description of the issue and its impact
- Steps to reproduce
- Any suggested fix, if you have one

You can expect a first response within a few days. Once the issue is fixed, it will be disclosed responsibly.
